# 그란데? 쇼츠 제작

한 줄 정의: **상식을 알려주고, "그런데"로 뒤집고, 거기에 맞는 팁을 준다.**
세로 9:16, 90~130초, 반말 내레이션. 채널 정보는 저장소의 `grande/CHANNEL.md`, 포맷 원본은 `grande/FORMAT.md`.

사람이 판단해야 하는 지점이 두 곳 있다: **뉴스 선택**과 **대본 검수**. 여기서는 반드시 멈추고 답을 받는다. 크레딧을 쓰는 이미지·음성 생성은 대본이 확정된 뒤에만 한다. 대본이 바뀌면 이미 만든 컷이 전부 버려지기 때문이다.

작업 폴더는 `grande/YYYY-MM-DD/`. 편마다 결과를 이 폴더에 기록하고 커밋·푸시한다.

## 1. 뉴스 후보 10개 → 사람 선택

국내 5·해외 5를 웹 검색으로 찾는다. 각 후보에 한 줄씩:
- 뒤집을 상식 ("다들 ~라고 알지")
- 그런데 반전 한 문장
- 붙일 수 있는 생활 팁(돈·건강·일)

상식도 팁도 없으면 탈락. 목록을 보여주고 멈춘다.

## 2. 대본 → 사람 검수

`scripts.md`에 편별로 쓴다. 컷 구성:

| 순서 | 역할 | 규칙 |
|---|---|---|
| 1 상식 | 다들 아는 것 | 5초 안. "당연하지"로 끝나는 문장 |
| 2 그런데 ① | 상식 뒤집기 | 10초 안. 이 반전이 영상의 질문 |
| 3 설명 | 왜 그런지 | 숫자는 타이포 카드로. 비유는 한 편에 하나 |
| 4 그런데 ② | 두 번째 반전 | 설명 중간이나 후반 |
| 5 주제 | 첫 상식으로 돌아와 한 문장 정리 | "결국 ~는 ~가 아니라 ~야" |
| 6 우리는? | 한국 상황·대비책 | 정부가 하는 것과 부족한 것 |
| 7 팁 | 오늘 할 수 있는 것 3개 이하 | 근거 있는 수치만. 마지막 줄은 주제와 이어지게 |

컷마다 `내레이션`, `[VOX]`(이미지 장면), `타이포`(화면에 뜰 종이 조각 키워드)를 적는다. 편 맨 위에 출처 링크, 맨 아래에 검수 포인트(가정한 환율, 확인 못 한 수치, 실존 인물·아이 얼굴 사용 여부)를 적는다. 검수 포인트는 사람이 사실 확인을 빨리 하게 하려는 것이니 숨기지 말고 다 적는다.

보여주고 멈춘다. 고칠 부분을 받으면 반영하고 다시 확인받는다.

## 3. 컷 이미지

Higgsfield `generate_image`로 컷당 1장. 프롬프트는 `references/style_prompt.md`의 템플릿에서 `SCENE:`만 바꾼다.
- 모델: `gpt_image_2_5`, flare, quality low, 2k, 9:16 (장당 0.5크레딧)
- 여러 장은 batch로 한 번에 돌리고 `jobs_wait` 후 결과 URL을 `cuts.json`에 편·컷 번호로 기록
- 실존 아이 얼굴은 쓰지 않는다. 실루엣으로

## 4. 내레이션

ElevenLabs `creative_generate_speech`, 컷당 1개, `generations_count: 1`.
- 보이스: '해철' `X0VqIIT9CdHJuR7QQEhH`, 모델 `eleven_multilingual_v2`
- 텍스트는 읽는 소리로 바꿔 넣는다: 숫자·영문·기호 → 한글 (`1,800만` → `천팔백만`, `CAR-T` → `카티`, `NEJM` → `엔이제이엠`). 화면 자막(`cap`)은 원래 표기를 쓴다
- 동시 요청은 3개까지. 넘으면 실패하니 3개씩 끊어서 돌린다
- ElevenLabs URL은 2시간 뒤 만료된다. 결과가 나오면 바로 Higgsfield `media_import_url`이 아니라 **`media_upload` + 샌드박스에서 curl로 받아 PUT** 해서 `d2ol7oe51mr4n9.cloudfront.net` 고정 URL을 만든다(`media_import_url`은 URL을 돌려주지 않는다). 길이(초)와 함께 `audio.json`에 기록

## 5. 렌더 매니페스트 `render_epN.json`

```json
{
  "title": "인트로에 뜨는 질문형 제목",
  "sting": "https://d2ol7oe51mr4n9.cloudfront.net/.../25306ea3-faac-416b-a908-3ba644e576da.mp3",
  "thumb": {"cut": 1, "lines": ["윗줄 6자 안팎", "아랫줄"]},
  "cuts": [
    {"img": "컷 이미지 URL", "aud": "내레이션 mp3 고정 URL",
     "tts": "TTS에 넣은 텍스트(읽는 소리)",
     "cap": "화면 자막(원래 표기)",
     "kw": [["stamp", "그런데", 0], ["pop", "주사 2번", "주사 두 번"], ["count", "1,800만 배럴", "천팔백만"]]}
  ]
}
```

`kw` 한 줄 = `[스타일, 화면 글자, 등장 시점]`.
- 스타일: `stamp`(빨간 도장 + 쿵 효과음, "그런데" 전용), `pop`(노란 종이 조각), `count`(숫자가 0부터 올라감)
- 등장 시점: `tts` 안의 문자열이면 그 말이 나올 때, 숫자면 컷 길이 대비 비율(0 = 컷 시작)
- `sting`은 인트로·아웃트로 로고에 나오는 여자 목소리 "그란데?" 사운드 로고. 위 URL을 그대로 쓴다

## 6. 렌더 (Higgsfield 샌드박스)

이 컨테이너는 Higgsfield CDN에 접근이 막혀 있어서 렌더는 `sandbox_exec`에서 한다. 스크립트는 `scripts/render.py`, `scripts/thumb.py`(저장소의 `grande/tools/`와 같은 파일).

1. 매니페스트를 커밋·푸시한다. 샌드박스는 `https://raw.githubusercontent.com/veletgoldmine-dot/lotto/<브랜치>/grande/...`에서 스크립트와 매니페스트를 받는다
2. 결과물 업로드 자리를 **먼저** `media_upload`로 만든다(샌드박스 파일은 호출이 끝나면 사라진다)
3. 한 번의 `sandbox_exec`(`background: true`)에서: 폰트 받기 → 렌더 → PUT 업로드
   - 폰트: `BlackHanSans.ttf` ← `https://github.com/google/fonts/raw/main/ofl/blackhansans/BlackHanSans-Regular.ttf`, `Nanum.ttf` ← `https://github.com/google/fonts/raw/main/ofl/nanumgothic/NanumGothic-Bold.ttf`
   - `python3 render.py epN.json out.mp4`. 편마다 폴더를 나눠 병렬로 돌린다(중간 파일 이름이 겹친다)
4. 호출 하나는 60초에 끊기니 `sleep 50` 이하로 나눠 로그를 확인한다. 로그 끝에 `done out.mp4 <초>`와 `PUT 200`이 나오면 `media_confirm`
5. 썸네일: `python3 thumb.py epN.json thumbN.jpg` → 같은 방식으로 업로드

## 7. 업로드 자료

`CHANNEL.md` 규칙대로 편마다 만든다.
- 제목: `[질문형 제목] | 그란데?`. 검색어(예: 국제유가, 주유소)를 앞쪽에
- 설명: 첫 줄 한 줄 요약 + "출처는 아래" → 해시태그 → 대본의 출처 링크 전부
- 태그: `그란데, 뉴스해설, 상식, 경제/건강, 생활팁` + 편별 키워드 3~4개

영상·썸네일·`업로드정보.txt`를 `그란데/` 폴더에 넣은 zip으로 묶어 올리고 링크를 준다.

이 세션은 클라우드에서 돌아서 유튜브에 직접 올릴 수 없다. 사용자가 올려 달라고 하면 이유를 한 줄로 말하고, Claude in Chrome(유튜브 스튜디오 로그인된 크롬)에 붙여 넣을 지시문을 준다. 지시문에는 파일명, 제목, 설명, 태그, 공개·아동용 아님, "게시 전 확인받기"를 넣는다.

## 8. 기록

`output.md`에 버전별 완성본 URL, 길이, 바뀐 점, 업로드용 제목·썸네일을 적고 커밋·푸시한다. 사람이 영상 링크를 주면 그것도 적는다.

## 한 컷만 고칠 때

해당 컷의 이미지나 음성만 다시 만들고 매니페스트의 그 컷 URL만 바꾼 뒤 6단계부터 다시 한다. 다른 컷은 건드리지 않는다.
