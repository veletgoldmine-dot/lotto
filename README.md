# 🍀 행운의 로또 번호 생성기

생년월일을 입력하고 버튼을 누르면 로또 번호(1~45 중 6개 + 보너스)를 뽑아주는 프로그램입니다.
누를 때마다 새로운 번호가 나옵니다.

## 구성

| 파일 | 설명 |
|------|------|
| [`lotto.html`](lotto.html) | 웹 버전 — 브라우저에서 바로 실행. 년/월/일 입력, 색깔 공이 룰렛처럼 돌다 멈추는 등장 연출, 사운드 효과 포함 |
| [`lotto.py`](lotto.py) | 터미널 버전 — 명령줄에서 실행 |

## 사용법

### 웹 버전
`lotto.html` 파일을 더블클릭하면 브라우저에서 열립니다.
년 / 월 / 일을 입력하고 **번호 생성하기**를 누르세요.

> 소리는 브라우저 정책상 버튼을 한 번 누른 뒤부터 재생됩니다.

### 터미널 버전
```bash
python3 lotto.py 1990-01-01     # 인자로 생년월일 입력
python3 lotto.py                # 실행 후 입력창에서 입력
```

## 특징

- **매번 랜덤** — 같은 생년월일이라도 실행할 때마다 다른 번호
- **날짜 검증** — 잘못된 날짜(예: 2월 30일)는 안내 메시지로 걸러줌
- 웹 버전은 외부 라이브러리 없이 HTML 파일 하나로 동작
