# 🎨 이미지 프롬프트 생성기

옵션을 고르면 이미지 생성용 프롬프트를 자동으로 조합해주는 도구입니다.
외부 라이브러리 없이 HTML 파일 하나로 동작합니다.

## 구성

| 파일 | 설명 |
|------|------|
| [`prompt-generator.html`](prompt-generator.html) | 웹 버전 — 브라우저에서 바로 실행 |

## 사용법

`prompt-generator.html` 파일을 더블클릭하면 브라우저에서 열립니다.
주제를 입력하고(영어 추천) 옵션을 고른 뒤 완성된 프롬프트를 복사하세요.

## 특징

- **형식 3종 전환** — 같은 선택으로 세 가지 형식의 프롬프트를 뽑을 수 있어요
  - **Midjourney** (기본, V8.1) — 키워드 나열 + `--ar`, `--v`, `--s` 파라미터 자동
  - **범용 문장** — ChatGPT/DALL·E, Gemini 등에 쓰는 자연스러운 서술형
  - **Stable Diffusion** — 키워드 + 네거티브 프롬프트(기본 제외어 자동 포함)
- **옵션** — 주제 · 화풍/스타일 · 조명 · 분위기 · 색감 · 구도/앵글 · 디테일 · 화면비(--ar) · 버전 · 스타일 강도(--s)
- **🎲 랜덤** 으로 옵션 자동 채우기, **📋 복사** 버튼, 실시간 갱신

> 대부분의 이미지 모델은 영어 프롬프트에서 가장 잘 동작합니다. 주제는 영어로 적는 걸 추천해요.

## 참고 — 특정 화풍 그대로 가져가기

키워드 묘사만으로 부족할 때는 Midjourney의 이미지 참조 기능을 쓰세요.

- `--sref <이미지URL>` — 스타일(색·붓질·질감)만 참조 (`--sw` 로 강도 조절)
- `--cref <이미지URL>` — 캐릭터 생김새 참조
- **무드보드(`--p` 코드)** — 여러 이미지를 모아 나만의 화풍을 학습시켜 재사용 (Midjourney 사이트의 Moodboards에서 생성)
