# 그란데 포맷

**한 줄 정의: 상식을 알려주고, "그런데"로 뒤집고, 거기에 맞는 팁을 준다.**

## 편 구조 (세로 9:16, 90~130초)
| 순서 | 역할 | 규칙 |
|---|---|---|
| 1 상식 | 다들 아는 것 | 5초 안. "당연하지"로 끝나는 문장 |
| 2 그런데 ① | 상식 뒤집기 | 10초 안. 빨간 도장 + 효과음. 이 반전이 영상의 질문 |
| 3 설명 | 왜 그런지 | 숫자는 전부 타이포 카드. 비유는 한 편에 하나 |
| 4 그런데 ② | 두 번째 반전 | 설명 중간이나 후반 |
| 5 주제 | 첫 상식으로 돌아가 한 문장으로 정리 | "결국 ~는 ~가 아니라 ~야" |
| 6 우리는? | 한국 상황·대비책 | 정부·제도가 하는 것과 부족한 것. 질문으로 끝내도 됨 |
| 7 팁 | 오늘 바로 할 수 있는 것 3개 이하 | 근거 있는 수치만. 마지막 줄은 주제와 이어지게 |

## 뉴스 선정 기준
- "그런데"로 뒤집을 상식이 있는가
- 시청자 생활(돈·건강·일)에 닿는 팁을 붙일 수 있는가
- 둘 다 아니면 탈락

## 제작 파이프라인
1. 뉴스 후보 10개 (국내 5·해외 5) → 사람이 선택
2. 대본 → 사람이 검수
3. 컷 이미지: GPT Image 2, `style_prompt.md`
4. 내레이션: ElevenLabs '해철' 보이스 (숫자·영문은 읽는 소리로 바꿔 입력)
5. 렌더: `tools/render.py` + 편별 `render_epN.json` (Higgsfield 샌드박스)
   - 흔들림 금지. 전환은 찢어진 종이, 키워드는 종이 조각, 그런데는 도장+효과음
